# OpenAloud

Бесплатный открытый Android-плеер для чтения документов и озвучивания текста.

## Исходники

Исходный проект пока добавляется из архива `OpenAloud.zip` в корне репозитория. После добавления архива GitHub Actions автоматически соберёт APK.

## Сборка APK

1. Добавьте `OpenAloud.zip` в корень репозитория (архив должен содержать папку `OpenAloud/`).
2. Откройте вкладку **Actions** и дождитесь завершения workflow **Android APK**.
3. В успешном запуске скачайте артефакт **OpenAloud-debug**.

## План разработки

1. Надёжная поддержка FB2, PDF и DOCX.
2. Очистка веб-страниц от меню, рекламы, комментариев и других лишних элементов.
3. Библиотека, история и закладки.
4. Размер шрифта и темы оформления.
5. Настраиваемые паузы между предложениями и предварительная подготовка следующего фрагмента.
6. Фоновое воспроизведение и корректное управление WakeLock/энергосбережением.

Интеграция с Ranobe Saver не входит в текущий проект и не планируется на этом этапе.

## Лицензия

Лицензия будет добавлена после проверки лицензий исходных компонентов и зависимостей.
