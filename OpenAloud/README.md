# OpenAloud — читалка с озвучкой (Android, Kotlin)

Сборка: Android Studio (Koala или новее, JDK 17) → File → Open → папка OpenAloud →
дождаться Gradle Sync → подключить телефон (отладка по USB) → Run ▶.
Либо Build → Build APK(s) и установить APK на телефон.

Что есть: TXT/EPUB, вставка текста или ссылки на страницу, «Поделиться» из браузера,
озвучка системным TTS в фоне (уведомление + кнопки), подсветка предложения,
тап по предложению, перемотка, главы, скорость/тон, таймер сна,
словарь замен, запоминание позиции, автоопределение русского/английского.
